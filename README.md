## 📌 About the Project

The **Pizza Sales Analysis Dashboard** is an end-to-end data analytics project built to understand pizza sales performance and customer ordering patterns.

The project starts with **raw pizza sales data**, which is cleaned, transformed, and analyzed using **MySQL and SQL**. The processed data is then connected to **Microsoft Power BI** to create an interactive dashboard that makes the insights easy to understand and explore.

The dashboard focuses on identifying **top-performing and low-performing pizzas**, analyzing sales and quantity, and understanding patterns across pizza categories and sizes.

---

## 🎯 What This Project Answers

The analysis helps answer questions such as:

- ⭐ Which are the **Top 5 Best-Selling Pizzas**?
- 📉 Which are the **Bottom 5 Pizzas**?
- 💰 Which pizzas contribute the most to sales/revenue?
- 📦 Which pizzas have the highest quantity sold?
- 🏷️ Which pizza categories perform best?
- 📏 Which pizza sizes are most preferred?
- 📊 What are the overall sales and order trends?
